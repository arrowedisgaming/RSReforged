# Security Policy

## Supported Versions

Only the latest release of RSReforged receives security fixes. If you are on an
older version, please update before reporting an issue.

## Reporting a Vulnerability

If you find a security issue (for example, a way for world data to execute
script in another user's client), please report it privately rather than in a
public issue:

- Use GitHub's private vulnerability reporting on this repository
  (**Security → Report a vulnerability**).

For anything that is not sensitive (hardening suggestions, deprecation
warnings, etc.), a regular [GitHub issue](../../issues) is fine.

Reports are typically acknowledged within a few days, and fixes ship in the
next release.
